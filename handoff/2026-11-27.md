### 装了什么

| 技能 | 来源 | 落在哪 |
|---|---|---|
| `watch` | bradautomates/claude-video 的 `skills/watch/` | `.dsh/skills/claude-video-watch/`（进仓库） |
| `video-perception` | jordanrendric/claude-video-vision 的 `skills/video-perception/SKILL.md` | `.dsh/skills/claude-video-vision/`（进仓库） |

- 两者的 `SKILL.md` 正文都逐字核对过，不是只看名字。
- `watch`：`setup.py --json` 先做 preflight，然后 `watch.py "<URL 或本地路径>" --question "问题"` 下载/抽帧/转录，报告里列出每一帧，agent 读完帧再回答。当前配置 `engine=local`、`backend=none`（不转录）、`detail=balanced`，状态 `setup_complete=true`、`missing_binaries=[]`。**调用必须传绝对路径**，相对路径会被解析到技能目录下。
- `video-perception`：强制流程 `video_info` → `video_analyze`（`filters` 必填）→ `video_watch` 抽帧 → `video_detail` 钻取。

### 音频链路踩的坑

1. 默认走 whisper.cpp 的 `whisper-cli`，本机没有，官方 releases 也没有 Windows 预编译包（`whisper-bin-x64.zip` / `-cuda.zip` 在 v1.9.6 都是 404）。改走 openai-whisper 的 Python 后端。
2. `pip install openai-whisper` 装了 20250625 + torch 2.15.0+cpu，`whisper.exe` 在 `D:\TmpProject\miniconda3\Scripts`。模型 `small.pt` 340 MB 在 `C:\Users\OVO\.cache\whisper\`。pip 报 label-studio 要 numpy<2.0 而当前 2.4.6，是既有冲突，没动。
3. **上游 bug**：`dist/backends/local.js` 的 `transcribeWithWhisperPython` 只解析 CLI 的 stdout，但 openai-whisper 默认 verbose，逐段日志打在 stdout、真正 JSON 写在 `<output_dir>/<basename>.json`，结果转录只剩一整段乱码。已在本地打补丁改为优先读 JSON 文件，代码里搜 `LOCALPATCH:read-json` 可确认；补丁脚本提交在 `.dsh/skills/claude-video-vision/patch-local-whisper-json.mjs`（幂等，`npm install` 覆盖 `dist/` 后重跑）。修完实测 25 s 样片能出干净分段时间轴。
